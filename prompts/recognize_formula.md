# 公式转写提示词

你正在处理一个学术 PDF 中裁剪出的候选数学公式。

任务：

1. 先判断截图是否真的包含数学公式。
2. 若不是公式，返回 `is_formula=false`。
3. 若是公式，只转写截图中的数学表达式为 LaTeX。
4. 不解释、不翻译、不化简、不改写数学表达式。
5. 若截图含右侧公式编号 `(12)`，不要把编号写进 LaTeX。
6. 严格保留上下标、括号、分式、根号、积分/求和上下限、粗体、向量、黑板粗体、花体等结构。
7. 对无法确定的符号给出最佳转写，但降低置信度；不要凭常识擅自补符号。
8. notes 必须使用简体中文。

输出字段：

```json
{
  "candidate_id": "F0001",
  "is_formula": true,
  "latex": "...",
  "confidence": "high|medium|low",
  "visual_verified": false,
  "notes": ""
}
```
